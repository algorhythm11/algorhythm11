## 🏪 VyaparAI --- AI-Powered Business Platform

`<a href="https://github.com/algorhythm11/VyaparAI">`{=html}
`<img src="card-vyaparai.svg" alt="VyaparAI" width="700"/>`{=html}
`</a>`{=html}

**VyaparAI** is a full-stack AI-powered business application built to
combine business management, analytics and AI assistance in a single
platform.

### ✨ Highlights

-   🤖 AI-powered business assistance
-   📊 Business dashboard and analytics
-   🔐 User authentication
-   👤 User management
-   ⚙️ REST API based architecture
-   🗄️ MongoDB database integration
-   🌐 Responsive React frontend
-   🧠 Gemini-powered AI capabilities
-   ☁️ Cloud deployment
-   🔄 Frontend ↔ Backend integration

### 🧰 Tech Stack

  Layer                 Technology
  --------------------- ---------------------------------
  Frontend              React, TypeScript, Tailwind CSS
  Backend               Python, FastAPI
  Database              MongoDB
  AI                    Gemini API
  Frontend Deployment   Vercel
  Backend Deployment    Render
  Version Control       Git & GitHub

### 🏗️ Architecture

``` text
                         ┌─────────────────┐
                         │      User       │
                         └────────┬────────┘
                                  │
                                  ▼
                    ┌────────────────────────┐
                    │    React Frontend      │
                    │ TypeScript + Tailwind  │
                    └───────────┬────────────┘
                                │
                           REST API
                                │
                                ▼
                    ┌────────────────────────┐
                    │    FastAPI Backend     │
                    │        Python          │
                    └───────────┬────────────┘
                                │
                    ┌───────────┴───────────┐
                    ▼                       ▼
             ┌──────────────┐       ┌──────────────┐
             │   MongoDB    │       │  Gemini API  │
             │   Database   │       │      AI      │
             └──────────────┘       └──────────────┘
```

### ☁️ Deployment

``` text
Frontend  → Vercel
Backend   → Render
Database  → MongoDB
Repository → GitHub
```

### ⚡ Performance Note

The frontend is deployed on **Vercel**, while the backend is deployed on
**Render**.

If the Render backend is using a sleeping/free instance, the **first API
request may take longer because the backend needs to wake up**. Later
requests can be faster once the server is active.

This is a normal cloud cold-start behavior and is not necessarily a
frontend loading problem.
